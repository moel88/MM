## 설치와 장착

게임을 종료하고 `mods`의 기존 보탠드 JAR를 `botand-2.19.0.jar`로 교체합니다. 멀티플레이에서는 서버와 모든 접속자가 같은 버전을 설치합니다. 기존 월드와 성장 데이터는 그대로 사용합니다.

보탠드 맵에서 관리자 명령어로 장착합니다.

```
/botand progress stand @s kageno
```

해제는 `/botand progress stand @s none`입니다. `@s` 대신 닉네임이나 대상 선택자를 지정할 수 있습니다. 검을 줍는 것만으로 자동 장착되지는 않습니다.

첨부한 검 사진을 기준으로 긴 검신, 날의 경사면, 꺾인 가드, 감긴 손잡이를 가진 입체 메시를 제작했습니다. 빈손이나 다른 아이템을 선택해도 검이 주 손에 표시되고 스킬을 사용할 수 있습니다. 1인칭, 3인칭, 왼손 설정과 다른 플레이어에게도 표시하며 인벤토리를 덮어쓰지 않습니다.

## R과 H의 멀티플레이 처리

- R은 발동 시 시전자 중심 반경 **3블록 이내**의 대상을 서버가 확정합니다. 시전자도 함께 멈춥니다. 이동, 낙하, 점프, 공격, 아이템 사용을 막고 시전자와 해당 대상의 화면 전체를 흑백으로 만듭니다. 반경 밖 플레이어의 화면은 바꾸지 않습니다.
- H는 발동 시 반경 **5블록 이내**의 모든 대상에게 동일한 시작 시각·카메라 경로를 전송합니다. 카게노를 장착하지 않은 피격자도 컷씬을 봅니다. 선택된 각 대상이 12회 참격을 받으며 범위 밖 플레이어는 강제로 카메라가 전환되지 않습니다.
- 거리에는 높이 차이도 포함합니다. 경계인 3블록·5블록은 포함합니다. 시전자를 자기 공격의 피해 대상에는 넣지 않습니다.
- PvP 비활성화, 관전자, 크리에이티브 무적과 팀 보호 같은 서버 규칙은 유지합니다. 상점 NPC는 공격 대상에서 제외합니다.
- 종료·사망·접속 종료·차원 변경·스탠드 해제·맵 비활성화 시 연출과 정지 상태를 정리합니다. 피해량·범위·T 누른 시간은 클라이언트가 지정하지 못합니다.

## 오버드라이브와 패시브

Q 음악은 사용자가 제공한 MP3의 **2분 14초(134초)**부터 잘라 OGG로 포함했습니다. 발동 때 한 번 재생하고 오버드라이브 종료·사망·맵 이탈 시 정지합니다. 음량은 레코드 음량과 기존 효과 음량 설정을 따릅니다.

오버드라이브는 기본 30초이며 공격 배율이 ×1.05에서 시작합니다. 적중할 때 0.01~0.02씩 배율이 올라가고 지속 시간이 조금 연장됩니다. 표식은 10초간 받는 피해를 15% 증가시키고 시전자에게 위치를 표시합니다. 구현상 배율 증가의 상한은 +1.0, 남은 지속 시간 상한은 90초입니다.

초재생은 평상시 2초마다 체력 0.5, 오버드라이브 중 1초마다 체력 1입니다. 밤에는 공격 피해가 35% 증가합니다. 다른 스탠드의 시간 정지 면역 연동 API도 마련했습니다. 아직 이 프로젝트에 없는 다른 스탠드의 시간 정지 동작 자체를 추가한 것은 아닙니다. **이번 R은 사용자 요청대로 카게노를 포함해 범위 안 대상을 정지**시킵니다.

영상에 쿨타임 수치가 명확하게 표시되지 않아 E 7초, R 12초, T 계열 공통 13초, Y 9초, Q 90초, H 30초를 적용했습니다. G는 기존 아토믹 쿨타임·야외·지상 조건을 유지합니다. 관리자 `/botand nocooldown on`, `/botand resetcooldown`도 새 스킬에 적용됩니다.

## 재현과 검증 범위

첨부 영상의 스킬 순서·키·타격 수·카메라 구성을 Minecraft의 플레이어 모델과 메시 효과로 재현했습니다. Roblox의 원본 코드나 모델을 그대로 이식한 결과물은 아니며, G는 기존 프로젝트의 아토믹 연출을 유지했습니다. 상세 관찰 기록은 소스의 `tools/kageno/reference.json`에 있습니다.

실제 Minecraft 클라이언트와 통합 서버에서 시전자 및 **카게노가 없는 피격자**로 R·H 패킷을 받아 화면 전환을 검증했습니다. 여러 서버 플레이어 대상, 반경 경계, 범위 밖 제외, 이동 패킷 차단, 피해, T 입력 분기와 돌진, E·Y·Q·G, 아이템 보존, 맵 이탈 정리를 검사했습니다. 배포 ZIP의 `verification`과 `preview`에 검사 결과와 실제 게임 캡처를 포함합니다. 별도 원격 멀티 서버나 사용자 기기의 그래픽 환경에서는 아직 실행하지 않았습니다.

# 보탠드 2.18.0 — 카게노 스탠드

Minecraft Java 1.20.1 · Fabric API 0.92.2+1.20.1 · Java 17.

## 설치

게임을 종료하고 mods 폴더의 기존 보탠드 JAR를 `botand-2.18.0.jar`로 교체합니다. 구버전과 동시에 넣지 않습니다. 멀티 서버와 모든 접속자도 같은 버전을 설치합니다. 기존 월드를 그대로 사용합니다.

## 장착과 해제

치트 또는 관리자 권한으로 보탠드 맵 안에서 실행합니다.

```
/botand progress stand @s kageno
/botand progress stand @s none
```

다른 플레이어에게 적용하려면 `@s`를 닉네임 또는 대상 선택자로 바꿉니다. 조회는 `/botand status`입니다. 기존 `/botand giveatomic` 명령어도 관리자용으로 유지됩니다.

새 카게노 장착은 현재 명령어로만 가능합니다. 아토믹 검을 줍거나 인벤토리에 넣거나 재접속해도 자동 장착되지 않습니다. 이전 저장 데이터에 이미 장착된 카게노는 유지됩니다.

## 검과 스킬

- 카게노 장착 중에는 빈손이거나 핫바에서 다른 아이템을 선택해도 주 손에 아토믹 검이 표시됩니다.
- 1인칭·3인칭과 다른 플레이어의 시점에 장착 상태를 반영합니다. 왼손잡이는 왼손에 검을 표시합니다.
- 검은 스탠드의 표시용 무기입니다. 핫바나 인벤토리 슬롯을 차지하거나 기존 아이템을 바꾸지 않습니다. 드롭할 수 있는 검을 매 틱 지급하는 방식이 아닙니다.
- 기존 아이템 사용 키인 **R**로 아토믹을 사용합니다. 아이템 사용 키를 따로 설정했다면 해당 키를 사용합니다. 카게노 장착 중에는 이 키가 스탠드 스킬을 우선합니다.
- 로카카카는 선택 후 **좌클릭 → 확인창의 사용하고 초기화**로 사용할 수 있습니다. 초기화하면 표시용 검과 스킬 권한이 함께 해제됩니다.
- 아토믹의 기존 쿨타임·야외/지상 조건·행동 제한과 연출은 그대로 적용됩니다. 카게노가 없으면 검 아이템만으로 아토믹을 사용할 수 없습니다.
- 이번 변경은 스탠드 장착·검 표시·기존 아토믹 연결입니다. 새로운 검 평타 콤보나 추가 스킬은 포함하지 않습니다.

장착 상태는 기존 UUID 기반 성장 데이터에 저장됩니다. 해제해도 레벨·경험치·환생·초월·돈과 인벤토리는 유지됩니다. 로카카카를 확정 사용한 경우에만 로카카카 1개를 소비합니다. 보탠드가 비활성인 맵에서는 스탠드 표시와 발동이 꺼집니다.

## 2.11.2 — 실제 맵을 보여주는 시작 화면

## 2.9.0 — 보탠드 전용 맵에서만 활성화

- 기존 3분의 1 도시의 `cliffcity` 데이터팩 안 arena/forest/spawn 함수 원본을 함께 확인해 전용 맵을 자동 인식합니다. 폴더 이름에 의존하지 않습니다. 해당 저장 파일의 오버월드만 켭니다.

- 일반 월드에서 바닐라 모델·HUD·웅크리기·우클릭·휠·F 손 바꾸기·Ctrl 달리기를 사용합니다. 보탠드 키가 일반 조작의 키 입력을 가로채지 않도록 라우팅합니다.
- 전용 맵 입장 때 원래 최대 체력 기준과 배고픔을 기록하고 퇴장/비활성화 때 복귀합니다. 체력 비율은 유지하며 성장 데이터는 지우지 않습니다. 이전 버전의 200 HP 값은 처음 이전할 때 일반 20 HP 기준으로 취급합니다.
- 카메라 시점과 변경한 키를 복구합니다. 임시 키 설정은 options.txt에 저장하지 않습니다. 이전 버전 기본 조합(R 사용/웅크리기 없음/Ctrl 없음/G 손 바꾸기)만 최초 실행 시 일반 기본값으로 이전하며 그 밖의 사용자 설정은 보존합니다.
- `/botand map status`는 누구나 사용합니다. 치트/OP 2 이상은 `/botand map enable`, `disable`, `auto`를 사용합니다. 명령 실행 차원에만 적용하고 `data/botand_map.dat`에 저장합니다. `auto`는 수동 지정을 해제합니다.

- 기존 스킬 모션·피해·타이밍·음원·효과 및 사용자 그래픽 설정은 유지합니다. 아래 기능은 전용 맵 안에서만 적용됩니다.

## 2.8.0 — 궁극기 임시 지형 파괴와 점진 복원

- 천외유성·천문검은 충돌 때, 아토믹은 기둥 생성 때 실제 블록을 제거해 충돌 없는 크레이터를 만듭니다. 공격 피해·범위·시전 모션·카메라·소리·흰 화면 타이밍은 유지합니다.
- 검은 **파괴 후 200틱 대기 + 20틱 반투명 복원**, 아토믹은 지속 중 크레이터를 유지하고 **공격 종료 후 200틱 대기 + 20틱 복원**입니다. 원래 블록 모델/텍스처가 smoothstep 알파 0→1로 보이며 마지막에 원래 충돌이 돌아옵니다. 상자·표지판 같은 블록 엔티티 전용 모델은 재질 윤곽을 먼저 표시한 후 정상 모델로 돌아옵니다.
- 원본 BlockState와 블록 엔티티 NBT를 **동일 청크의 보관 블록 한 개**에 저장합니다. 청크 저장과 별도 파일 저장 순서가 엇갈리지 않습니다. 블록마다 틱/블록 엔티티를 만들지 않습니다. 블록 엔티티는 드롭 콜백 전에 분리하여 아이템 복제를 막으며 청크 전송용 NBT에는 개인 인벤토리 내용을 넣지 않습니다.
- 중첩 시전은 첫 원본을 유지하고 복구 시점만 연장합니다. 임시로 빈 칸은 비충돌/비가시 블록으로 예약해 플레이어 설치·유체·피스톤·다른 변경으로 원본을 덮어쓰지 못하게 합니다. 클라이언트는 일반 투명 블록 아틀라스 렌더를 사용하며 새 후처리나 셰이더 팩은 없습니다.
- 복원되는 수직 구역에 있는 플레이어를 머리 위 공간이 확보된 지상으로 이동시키고 낙하 속도/누적 낙하 거리를 초기화합니다. 관전자는 이동하지 않습니다. 멀리 떨어진 사람도 이동하지 않습니다.
- 저장한 월드를 재시작하거나 청크를 다시 불러오면 복구 정보를 이어갑니다. 이미 만료된 청크를 다시 불러오면 20틱의 반투명 복구를 진행합니다. `/botand clear`는 컷씬만 중단하며 지형 복구 정보를 없애지 않습니다.
- 기본 지형 상한은 반경 48, 깊이 10, 타격 지면 위 20블록이며 중앙에서 가장자리로 순차 처리합니다. 한 시전당 65,536블록, 서버 틱당 파괴 약 1,024블록(수직 열 단위 마무리), 복원 약 2,048블록(청크 작업 단위 마무리)입니다. 로드된 청크만 처리하고 강제 청크 로딩은 하지 않습니다.
- 기반암 등 음수 경도 블록, 물/용암/수중 블록, 포털, 이동 중 피스톤은 보존합니다. 기존 공격 반경 96 및 아토믹 반경 28과 지형 상한은 별개입니다.
- 설정 `terrainDamage`, `terrainRadiusLimit`(4~64), `terrainDepth`(1~16), `terrainAboveGround`(0~32). 설정 버전 7로 자동 이전하며 사용자 후처리/렌더링/음량 설정은 보존합니다. 끈 뒤에도 이미 파괴된 지형의 복원은 계속됩니다.
- 복원 전 모드를 제거/다운그레이드하면 보관 블록을 읽을 수 없으므로 먼저 해당 지역을 로드해 복원을 마치고 저장해야 합니다.
- 시간은 20 TPS 기준입니다. 실제 모바일 장치 FPS/그래픽은 검증하지 않았습니다.

아래는 이전 버전 기록이며 지형 파괴 정책은 2.8.0이 우선합니다.

## 2.7.0 — 사진 HUD / 체력 200 / 레벨·환생·초월

- 사용자 PNG 원본을 변경 없이 그대로 모드에 넣었습니다. 왼쪽 위에 캐릭터·리본·테두리를 표시하며, 안쪽 막대와 숫자는 게임에서 따로 그려 실시간 수치를 표시합니다. PNG의 예시 숫자 275/30/50/5/2가 고정되지 않습니다. 오른쪽 작은 지도 그림은 원본 장식이며 실제 미니맵 기능은 아닙니다.
- 실제 최대 체력을 **200 HP**로 설정합니다. 표시만 10배 하는 방식이 아닙니다. 피해·회복·사망·서버 동기화는 실제 HP를 사용합니다. 기존 체력 20→200 전환은 현재 체력 비율을 유지합니다(예: 15/20→150/200).
- 파란 막대는 **남은 가드 100**입니다. 맨손 평타를 막으면 100→75→50→25→0으로 줄고 4타에 가드가 깨집니다. 기존 1초간 90% 둔화/행동 금지와 복구 규칙을 유지합니다. 회복 마지막 수치도 동기화해 99에서 멈추는 표시를 방지합니다.
- 바닐라 하트·배고픔·경험치 표시를 새 HUD로 대체합니다. 방어구·수중 호흡·핫바·기존 대시/콤보 표시는 유지합니다. F1·관전·컷씬 중에는 새 HUD도 숨깁니다.
- 배고픔 자체를 비활성화하여 굶주림 피해나 배고픔 때문에 달리기가 막히는 일이 없습니다. 배고픔에 의존한 자연 회복도 발생하지 않습니다. 물약 등 기존 직접 회복 효과는 유지합니다. 별도 자동 회복 규칙은 아직 추가하지 않았습니다.
- 신규 플레이어는 **레벨 1 / 환생 0 / 초월 0**으로 시작합니다. 레벨은 최대 50이고 50일 때 `[MAX]`가 표시됩니다.
- `/botand rebirth`: 레벨 50일 때 레벨 1로 초기화하고 노란 환생 수를 1 올립니다. 환생 15회이면 먼저 초월해야 합니다.
- `/botand transcend`: 환생 15회일 때 환생 수를 0으로 초기화하고 파란 초월 수를 1 올립니다. 현재 레벨은 유지합니다. 환생/초월은 사망·관전·공격·가드·경직·대시·컷씬 중에 사용할 수 없으며 체력을 채워 주지 않습니다.
- `/botand status`: 체력·레벨·환생·초월·스탠드 정보를 표시합니다. 채팅의 환생/초월 버튼도 누를 수 있습니다. 이 세 명령어는 일반 플레이어에게 허용됩니다.
- 데이터는 UUID별로 월드의 `data/botand_progress.dat`에 저장하며 사망·재접속·차원 이동·서버 재시작으로 초기화되지 않습니다. 새로운 월드는 별도 기록입니다.
- 스탠드 체력은 `StandStats`가 결정합니다. `none`과 `kageno`를 등록했고 현재는 둘 다 200 HP입니다. 카게노도 스탠드로 저장되며, 스탠드 소환/획득 방식이나 종류별 체력 차이는 아직 정하지 않았습니다. 이번의 스탠드 설정 명령어는 체력 프로필을 선택합니다.
- 경험치 획득처·레벨별 요구 경험치는 미정이므로 임의의 사냥 경험치나 자동 레벨업을 추가하지 않았습니다. `ProgressManager.grantLevels`로 이후 보스·퀘스트 보상을 연결할 수 있고 현재는 아래 관리자 명령어로 레벨을 조절합니다. 바닐라 인챈트용 경험치는 별개로 남습니다.
- 일반 더미는 **200 HP**, 콤보 더미는 **2,000 HP**입니다. 기존 더미는 로드할 때 남은 체력 비율을 유지해 옮깁니다. 이를 지원하도록 최대 체력 속성의 허용 상한만 100,000으로 확장했습니다. 다른 몹의 실제 체력은 바꾸지 않습니다.

관리자/치트 명령어:
```
/botand progress setlevel @s 50
/botand progress addlevels @s 1
/botand progress setrebirths @s 15
/botand progress settranscendence @s 2
/botand progress stand @s kageno
/botand progress stand @s none
```

기존 `/botand giveatomic`, 더미·쿨타임 등 관리자 명령어의 OP 제한은 유지합니다.
`preview/Botand_HUD_2.7.png`는 실제 HUD 배치 코드·원본 PNG·Minecraft 글꼴로 그린 상태별 확인용 렌더입니다. 실제 모바일 게임 녹화/스크린샷은 아닙니다.

## 3인칭 카메라와 행동 제한

기본 5.5블록, 최대 14블록의 로블록스 Classic 방식 조작입니다. 자유 시점에서는 WASD를 카메라 기준으로 변환하며 몸이 이동 방향으로 회전합니다. 시프트 락·1인칭에서는 시선을 유지하면서 기존 옆걸음/뒷걸음 모션을 사용합니다. 회전 감도와 반전 Y는 Minecraft 설정을 따릅니다.

카메라 거리와 어깨 이동은 렌더 주기와 독립적으로 보간합니다. 8개 모서리 레이로 벽을 확인해 즉시 당기고, 다시 넓어질 때만 천천히 복귀합니다. 가까운 벽에서 자기 몸이 화면을 가리지 않도록 로컬 플레이어 모델을 숨깁니다. 어깨 시점 조준은 플레이어 눈 위치에서 재계산하며 사거리와 벽 차단 판정을 유지합니다. 컷씬은 우선권을 가지며 종료 후 선택한 줌/시프트 락 상태로 돌아옵니다.

가드 파괴의 20틱 동안 90% 감속과 함께 공격·아이템·상호작용·채굴·스킬·대시·가드·점프·달리기·인벤토리 조작·슬롯 변경·버리기·손 교환을 막습니다. 이동과 시점, 채팅/Esc는 유지합니다. 서버 스레드에서 패킷과 일반 상호작용 경로를 모두 검사하고 예측된 블록/인벤토리를 다시 동기화합니다. 진행 중인 아이템 사용과 채굴도 취소합니다.

우클릭은 카메라에 예약되어 기본 아이템 사용 키를 R로, 기본 웅크리기/달리기 키는 새 Shift/Ctrl 기능으로 이전합니다. 사용자 지정 아이템 사용 키는 보존합니다. 새 달리기는 바닐라 더블탭 달리기를 대신합니다. 일반 기력/음식 조건은 유지합니다. 모드가 설치된 서버에서만 새 카메라가 활성화됩니다.

## 2.2 확정 콤보와 피격 경직

1타가 실제 명중하고 공격자가 다음 타격을 회수 구간에 예약하면 4타까지 경직이 이어집니다. 좌클릭을 계속 누르는 기존 입력으로 연결할 수 있습니다. 1~3타는 서버가 관리하는 대상 유지와 이동/행동 차단을 적용하고, 4타는 먼저 경직을 풀어 기존 넉백이 정상 적용됩니다. 가드로 막힌 첫 타격은 콤보를 잡지 않습니다.

기존 접촉 시점은 시작 후 3/14/26/40틱입니다. 접촉 사이가 11/12/14틱이므로 2틱(0.1초) 경직으로는 확정 연결이 되지 않습니다. 다음 접촉까지 경직을 유지하되 현재 타격 종료 시 다음 입력이 예약되지 않았으면 즉시 해제합니다. 새로운 콤보 번호로 기존 경직을 재활용할 수 없고 매 경직에 만료 시간을 둡니다.

후속 타격은 잡힌 대상을 보정하지만 3.15블록 사거리, 벽과 PvP 피해 규칙을 통과해야 합니다. 공격자가 피해를 받거나 무기를 들면 중단하고, 사망/접속 종료/차원 이동/사거리 이탈/벽 차단도 해제합니다. 플레이어의 예측 이동과 서버 이동 패킷을 모두 제한합니다. 몬스터는 AI 처리를 일시 중지하지만 영구 AI 비활성 플래그는 바꾸지 않습니다. 중력과 낙하는 유지합니다.

기존 카메라/모션 미리보기는 2.1 및 2.0 때 렌더한 파일입니다. 이번 콤보는 자동 검사와 전용 서버에서 검증했으며 실제 플레이 녹화는 제공하지 않습니다.

## 가드와 대시

가드는 F를 누르는 동안 정면 약 157도 범위의 막을 수 있는 공격을 방어합니다.
뒤에서 오는 공격, 낙하·질식처럼 방향이 없는 피해, 방패를 무시하는 피해는 막지 않습니다.
막을 때마다 게이지가 오릅니다. 증가량은 `18 + 입력 피해 × 5`, 타격당 최대 45입니다.
100에 도달하면 해당 공격은 막고 가드가 깨집니다. **20틱(정상 속도 1초) 동안 이동속도 90% 감소**, 공격·대시·가드·새 스킬 시작을 제한합니다.
1초가 끝나면 게이지와 전용 감속이 해제됩니다. 일반 가드 중에는 이동속도를 55% 줄입니다.
마지막 가드 타격 1.5초 후부터 게이지가 감소하며 F를 떼면 더 빠르게 회복합니다.

대시는 7틱(0.35초)의 지상 이동 가속이며 재사용 대기시간은 24틱(1.2초)입니다.
방향은 시작할 때 고정하고 대각선도 같은 속도로 정규화합니다. 지형/마찰/충돌에 따라 이동 거리가 달라집니다.
벽을 관통하는 순간이동, 무적, 별도 대시 피해는 추가하지 않았습니다.
탈것·수영·비행·공중에서는 시작하지 않습니다. 공격 중이나 가드 중에도 시작하지 않습니다.
화면 아래 게이지에 가드 부담과 대시 준비 상태, 공격 중에는 4타 진행을 표시합니다.

모델·코드와 천외유성 효과음은 독립 제작했습니다. 아토믹에는 사용자가 제공한 영상의 37초 오디오를 포함합니다.

## 천문검 · 황금 강림

제공된 GIF의 컷 순서와 화면 배치를 참고하고, 검이 천천히 박히는 장면을 늘려 12.2초 Minecraft 3D 컷씬으로 구성했습니다.
플레이어 스킨, 블록식 몸체, 입체 구름 메시는 원본 캐릭터와 애니메이션의 100% 동일 복제가 아닙니다.
GIF/동영상 파일이나 추출 프레임을 화면에 재생하지 않습니다. 관전자도 월드 안의 거대 검과 구름을 봅니다.

```text
/give @s celestialfall:heaven_sword
```

주 손에 검을 들고 **야외에서 12–128블록 앞의 땅을 조준하고 R(아이템 사용 키)을 누릅니다**. 128블록은 기본 `castRange`입니다.
처음 1.4초 동안 시작점에서 1.5블록 넘게 움직이거나 사망·차원 이동하면 취소됩니다.
그 뒤에는 표시한 착지 지점에서 주문이 계속됩니다. 탈것·수중에서는 사용할 수 없습니다.

| 시간 | 연출 |
| --- | --- |
| 0–1초 | 두 손가락을 세우며 손끝의 금빛을 모으는 근접 컷 |
| 1–1.4초 | 플레이어 얼굴 앞에 검결을 세우고 작은 금빛 십자 섬광 |
| 1.4–3.1초 | 푸른 소용돌이와 문양이 새겨진 거대 황금 검 등장 |
| 3.1–5초 | 중거리 고정 위치에서 시선만 일부 하강을 추적, 검 끝과 착지 지면을 함께 표시 |
| 5초 | 지면 접촉, 1000 피해 한 번, 첫 충격파·파편·지면 연기 |
| 5–9초 | 검이 96블록 깊이로 천천히 박힘. 금빛 분출·추가 파편·지속 저음 |
| 9–11초 | 마지막 충격파 뒤 박힌 검과 잔해를 보여줌 |
| 11–12.2초 | 플레이어 시점으로 부드럽게 복귀 |
| 13.5–17초 | 박힌 검과 남은 효과가 사라짐 |

검신은 길이 720블록/최대 폭 142블록, 전체 검은 920블록입니다.
구름의 안쪽 빈 공간 주변에 밝은 구름층이 생기고 바깥 나선 구름은 약 700블록까지 뻗습니다.
근접 컷은 별도 두 손가락 모델을 사용합니다. 얼굴은 플레이어 스킨을 사용하고 준비 동작 때 파랑·흰색 의상을 표시합니다.

화면 전체를 하얗게 덮는 효과는 없습니다. 금빛 섬광은 손끝과 착지 지점에만 표현합니다.
천문검에는 새 영상의 정상 속도 소리를 영창/접촉/최종 폭발로 나누어 적용했습니다. 시작은 0.05초, 접촉은 5초, 최종 폭발은 9초입니다. 관입이 오래 걸리는 부분만 목소리 없는 합성 바람·저역 울림으로 연결하며, 음원의 재생 속도나 피치를 낮추지 않습니다.

착지 순간 기본 반경 **96블록 안 몬스터에게 1000 마법 피해를 한 번** 줍니다.
플레이어·동물·주민은 대상이 아니며 실제 블록·물·상자를 변경하지 않습니다. 몹 고유의 방어·무적 규칙은 적용될 수 있습니다.
파편은 지형을 복사한 렌더 전용 물체입니다. 아이템으로 떨어지거나 회수되지 않습니다.
기본 대기시간은 45초입니다. 상시 해제를 켜도 진행 중인 기술은 끝나야 다음 기술을 사용할 수 있습니다. 천문검의 월드 효과는 17초에 종료됩니다.

| 새 설정 | 기본값 | 설명 |
| --- | --- | --- |
| heavenDamage | 1000 | 착지 때 몬스터 피해. 0이면 관상용 |
| heavenImpactRadius | 96 | 몬스터 피해 반경, 2–160블록 |
| heavenCooldownSeconds | 45 | 재사용 대기시간, 11–300초 |

기존 설정을 백업 후 버전 5로 이전합니다. 이전 천문검 기본 피해 200은 1000으로 올리며, 다른 천문검 피해값·아토믹 설정·음량은 유지합니다.
제작법: 네더라이트 검을 가운데, 금괴를 위·좌·우, 네더의 별을 아래에 배치합니다.
OP 명령어: `/celestialfall giveheaven`, `/celestialfall heaven`. V는 시점만 복귀하며 `/celestialfall clear`는 전체 주문과 소리를 정지합니다.
3D 월드 효과를 볼 때 렌더 거리가 짧으면 실제 지형이 일부 비어 보일 수 있습니다. 효과 때문에 미로딩 청크를 강제로 생성하지 않습니다.

## 아토믹 · 섀도우 소드 — 37초 영상 버전

기존 천외유성 인장과 별개의 검입니다. 사용자가 제공한 1기 5화 영상의 순서를 기준으로 다시 구성했습니다.

```text
/give @s celestialfall:atomic_sword
```

주 손에 검을 들고 야외의 땅 위에서 R(아이템 사용 키)을 누릅니다. 시전자 위치를 중심으로 발동합니다.
처음 **6.5초** 동안 시작점에서 1.5블록 넘게 이동하거나 사망·차원 이동하면 취소됩니다.
검을 내려친 뒤에는 원래 시작점에서 연출이 계속됩니다. 탈것·수중에서는 시작할 수 없습니다.
천외유성·아토믹·천문검은 서로 겹쳐 시전하지 않습니다. 취소해도 60초 대기시간은 유지됩니다.

| 시전 후 시간 | 아토믹 연출 |
| --- | --- |
| 0–4.4초 | 머리 위로 든 검, 회로와 마력, 대사에 맞춘 근접 컷 |
| 4.4–4.9초 | 검을 빠르게 내려치는 동작 |
| 4.9–7.1초 | 양팔을 아래로 벌린 마무리 자세 |
| 7.1–7.8초 | 가느다란 참격과 자세 회수 |
| 7.7–15.0667초 | 흰 화면만 표시, 검정 파편 없음 |
| 15.0667–15.5초 | 외부 시점으로 전환 |
| 7.7–33초 | 경기장 크기의 보라색 기둥, 번개와 압력파 (처음에는 흰 화면 뒤에 존재) |
| 33–37초 | 수평 반경만 수축, 높이 70 유지 |
| 36.8–37초 | 플레이어 시점 복귀와 종료 |

빛기둥의 **기본 지름은 56블록, 높이는 70블록**입니다. 33초부터 37초까지 수평 폭만 부드럽게 줄어 사라집니다.
영상의 굵기와 화면 구도를 참고한 게임용 비율이며 원작의 공식 반경이나 픽셀 단위 일치로 검증한 수치는 아닙니다.
검은 후드·코트·망토의 관절 모델과 플레이어 스킨 얼굴을 사용하며, 실제 착용 장비는 이 모델에 표시하지 않습니다.
영상 속 다른 등장인물·도시·물결은 복제하지 않으며 해당 구간은 게임 지형 위의 카메라·먼지·압력파로 표현합니다.

**빛기둥 속 몬스터는 7.7초부터 36.7초까지 1초 간격으로 50 피해**를 받습니다. 총 30회 판정하며, 매번 현재 범위 안의 몬스터를 조회합니다.
반경은 최대 28블록, 높이는 시작점 아래 2블록부터 위 70블록까지이며 수축 시 반경만 줄고 높이는 유지됩니다. 가장자리에서도 피해가 줄지 않습니다.
Minecraft의 Monster 유형에 해당하는 살아 있는 몬스터만 대상이며 플레이어·동물·주민·길들인 동물은 제외합니다.
피해 종류는 방어구·저항 효과·보호 마법부여의 피해 감소를 무시합니다. 흡수 체력이나 몹 고유의 무적 상태 등 게임 규칙은 적용될 수 있습니다.
로딩된 몬스터만 판정하고 청크를 강제 로딩하지 않습니다. 실제 블록·물·건물·상자는 보존됩니다.
관상용은 `atomicDamagePerSecond=0`으로 설정합니다. 천외유성의 `damage`와 독립적입니다.

**아토믹 오디오는 제공받은 영상의 처음 37초를 변환한 트랙**입니다. 음악만 분리한 것이 아니라 대사·효과음이 섞인 원래 믹스입니다.
37초짜리 한 트랙을 한 번 재생하며 종료·취소·월드 이탈 시 정지합니다. 늦게 범위에 들어온 관전자에게 지나간 구간을 처음부터 재생하지 않습니다.
V로 시점만 건너뛰면 주문과 오디오는 계속됩니다. `effectVolume=0`이면 음소거됩니다.
정상적인 초당 20틱 기준으로 영상과 타이밍을 맞췄으며 서버가 느리면 영상 효과와 오디오가 어긋날 수 있습니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| atomicVisualRadius | 28 | 빛기둥과 몬스터 피해의 공통 최대 반경, 8–768블록 |
| atomicDamagePerSecond | 50 | 몬스터에게 매초 주는 피해, 0–1000 |
| atomicCooldownSeconds | 60 | 대기시간, 10–300초 |
| atomicCostume | true | 검은 후드·코트. false이면 플레이어 스킨 사용 |

1.4.0의 `atomicDamage`와 `atomicDamageRadius`는 이 버전에서 사용하지 않습니다.
기존 설정은 백업한 뒤 버전 6으로 옮기며 반경을 28로 줄입니다. 지속 피해는 기존 값을 유지합니다. 그래픽·음량 등 기존 선택은 유지합니다.
공통 `cinematicCamera`, `postProcessing`, `screenFlash`, `effectVolume`도 적용됩니다.
1.5.1에서는 화면 전체를 덮는 흰 섬광과 흑백 반전·흰 배경을 제거했습니다. 검은 파편 잔상은 원래 장면 위에 반투명하게 표현하며 `screenFlash=false`로 끌 수 있습니다.
렌더 거리가 짧으면 원경 컷에서 실제 지형이 비어 보일 수 있습니다. 효과 때문에 미로딩 청크를 생성하지 않습니다.

OP: `/celestialfall giveatomic`, `/celestialfall atomic`, `/celestialfall clear`.
제작법은 네더라이트 검을 가운데, 자수정 조각을 위·좌·우, 네더의 별을 아래에 배치합니다.

## 천외유성 연출

- 플레이어 뒤 → 별자리 원경 → 검 근접 → 낙하 추적 → 지상 저각도 → 폭발 원경의 6단계 컷씬.
- 장면별 FOV와 화면 기울기, 별자리 충돌·폭발에 맞춘 진동.
- 하늘의 검은 틈, 번개 균열, 검 문양의 순차 점등과 큰 「天外流星」 컷인.
- 가속 낙하, 나선형 빛의 띠, 공기 압축 고리와 화면 속도선.
- 착탄 직전 주문 효과음 정적과 0.2초의 검·카메라 정지. 월드 전체의 시간을 멈추지는 않습니다.
- 흑백 임팩트, 밝은 섬광, 시차를 두고 퍼지는 세 충격파와 후속 폭음.
- 카메라 쪽으로 튀는 거대 파편, 두꺼운 먼지벽, 상승 연기와 보라색 잔광.
- 자체 후처리 셰이더의 빛 번짐, 방사형 왜곡·잔상과 색수차. 별도 셰이더 팩은 필요하지 않습니다.

보라색 빛은 표면 색광·발광 형상·후처리 블룸으로 표현합니다. RGB 블록 조명이나 물리적 그림자 엔진은 아닙니다.

## 설치와 업데이트

1. PC 자바 에디션 1.20.1을 준비합니다.
2. https://fabricmc.net/use/installer/ 에서 1.20.1용 Fabric Loader를 설치합니다. Loader 0.15.6 이상이 필요합니다.
3. 게임을 종료하고 **기존 celestial-fall JAR(1.2.0 포함)을 mods 폴더에서 제거**합니다.
4. `botand-2.4.0.jar`와 1.20.1용 Fabric API를 mods에 넣습니다. 설치 묶음에는 `fabric-api-0.92.2+1.20.1.jar`가 들어 있습니다. API를 중복 설치하지 마세요.
5. Fabric 1.20.1 프로필로 실행합니다.

Windows 기본 경로: `%APPDATA%\.minecraft\mods`. 별도 게임 디렉터리를 쓰면 해당 디렉터리에 설치합니다.
**Fabric API가 필요합니다.** 서버와 클라이언트 모두 같은 2.4.0 모드와 Fabric API를 설치해야 합니다.
통신 형식이 달라 이전 버전과 연출을 공유하지 않습니다. Forge / NeoForge / 베드락용은 아닙니다.

## 사용

```text
/give @s celestialfall:astral_sigil
```

야외에서 128블록 이내의 땅을 보고 R(아이템 사용 키)을 누릅니다. 목표 위로 하늘이 뚫려 있어야 합니다.
인장은 소모되지 않으며 크리에이티브 전투 탭에서도 찾을 수 있습니다.

| 시전 후 시간 | 연출 |
| --- | --- |
| 0–5초 | 부유하는 돌과 하늘의 거대 별자리 |
| 5.6 / 6.2 / 6.8초 | 세 별자리 충돌, ‘쿵·쿵·쿵’ |
| 6.8초 | 검은 틈과 제목 컷인, 검 근접 장면 |
| 7.8–10.1초 | 검이 가속하며 낙하, 추적·저각도 장면 |
| 10.1–10.3초 | 검과 카메라 정지, 흑백 임팩트 |
| 10.3 / 10.9 / 11.6초 | 세 충격파와 폭음, 파편·연기 |
| 16.5–18.5초 | 플레이어 시점으로 복귀 |
| 30–34초 | 검과 남은 잔광 소멸 |

정상적인 초당 20틱 기준입니다. 서버가 느리면 실제 소요 시간이 늘어납니다.
**V 키**로 컷씬을 건너뛰어 시점을 되돌립니다. 이미 시작된 주문 연출은 계속됩니다.
자신의 시전에만 자동 컷씬이 켜집니다. 플레이어를 순간이동시키지 않으며 이동·공격도 계속 가능합니다.
기본 대기시간은 40초이며 동시 시전은 1개입니다.

실제 지형을 보존해도 **몹 피해는 유지**됩니다. 기본 중심 피해 200, 반경 96블록이며 거리에 따라 감소합니다.
플레이어 피해는 기본적으로 꺼져 있습니다. 순수 관상용으로 쓰려면 서버 설정의 `damage`를 0으로 바꿉니다.

OP 명령어:

```text
/celestialfall give
/celestialfall cast
/celestialfall clear
/celestialfall reload
```

`clear`는 현재 연출과 대기시간을 초기화합니다. `cast`에도 조준·야외·대기시간 검사가 적용됩니다.

## 설정

파일: `config/celestialfall.json` / 전체 예시: `CONFIG_EXAMPLE.json`.
버전 4 이하의 설정은 처음 읽을 때 `celestialfall-before-v190-시간값.json`으로 백업한 뒤 버전 5로 이전합니다.
기존 그래픽·소리·피해 선택은 보존하고 지형 파괴를 끕니다. 새 후처리 항목은 기본적으로 켜집니다.
이전에 컷씬이나 연기 등을 껐다면 해당 선택도 유지됩니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| terrainDamage | false | 이전 설정 호환용. true로 바꿔도 파괴하지 않음 |
| damage | 200 | 중앙 몹 피해, 0–1000. 0이면 피해·넉백 없음 |
| impactRadius | 96 | 몹 피해 반경, 2–160. 시각 효과 크기와 별개 |
| damagePlayers | false | 천외유성의 플레이어 피해 허용. 아토믹은 몬스터만 대상 |
| hurtCaster | false | damagePlayers도 true일 때 시전자 피해 허용 |
| castRange | 128 | 시전 거리, 8–256 |
| cooldownSeconds | 40 | 대기시간, 5–300초 |
| maxActiveCasts | 1 | 동시 연출 상한, 1–4 |
| visualQuality | 2 | 0=낮음, 1=중간, 2=높음. 파편·연기 개수 조절 |
| cinematicCamera | true | 자동 컷씬 |
| screenShakeStrength | 0.65 | 진동 강도, 0–1 |
| postProcessing | true | 자체 화면 후처리 전체 |
| bloomStrength | 1.35 | 빛 번짐 강도, 0–2.5 |
| screenDistortion | true | 충격파 왜곡과 색수차 |
| animeImpactFrames | true | 흑백 임팩트 |
| speedLines | true | 낙하 속도선과 방사형 잔상 |
| screenFlash | true | 착탄 섬광. false이면 흑백 임팩트도 끔 |
| flyingBlocks | true | 부유하는 돌과 거대 파편 |
| explosionSmoke | true | 연기와 먼지벽 |
| purpleGlow | true | 표면 색광·기둥·화면 가장자리 잔광 |
| purpleGlowStrength | 0.8 | 색광 강도, 0–1 |
| skyEffect | true | 밤하늘·별 배경 |
| titleOverlay | true | 제목과 컷인 |
| effectVolume | 0.8 | 주문 소리, 0–1 |

서버 설정은 피해·시전 규칙을, 각 클라이언트 설정은 화면·소리를 결정합니다.
서버는 `/celestialfall reload`로 다시 읽습니다. 원격 서버에서 개인 그래픽 설정을 바꾼 경우 클라이언트를 재시작합니다.

## 그래픽과 성능

파편은 실제 블록 엔티티가 아닌 시각적 복사본입니다. 회수할 수 없고 건물·상자 내용물을 제거하지 않습니다.
기존 텍스처 파편·연기는 각각 240개·361개 상한입니다. 아토믹은 추가로 기둥 주변의 렌더 전용 암석 최대 161개와 연기 덩어리 최대 110개를 배치합니다. 복잡한 파괴 물리 엔진 대신 낙하·회전·튕김을 표현합니다.
블룸은 화면의 1/4 가로·세로 해상도에서 계산합니다. 효과 종료 시 화면은 원래 상태로 돌아옵니다.

거대한 형상이 잘리지 않도록 원거리 평면을 확장하지만, 미로딩 지형을 강제로 불러오지는 않습니다.
천외유성은 렌더 거리가 짧으면 카메라를 당길 수 있으며, 아토믹은 거대한 기둥을 보여주는 원경 구도를 유지합니다.
파편·연기가 무거우면 `visualQuality=0`, 후처리를 끄려면 `postProcessing=false`로 설정합니다.
외부 셰이더와 화면 충돌이 있으면 우선 자체 후처리를 끄고 비교할 수 있습니다.
실제 FPS와 Iris/Sodium/OptiFine 및 다른 모드 조합은 아직 검증하지 않았습니다.

자수정 조각 3개(위 중앙·가운데 왼쪽·가운데 오른쪽), 네더의 별 1개(가운데), 금괴 1개(아래 중앙).

## 빌드와 검증

JDK 17, Gradle 8.6, Fabric Loom 1.1.14, Yarn 1.20.1+build.10.

```text
Windows: gradlew.bat build
macOS/Linux: ./gradlew build
```

결과: `build/libs/botand-2.4.0.jar`. 생성된 리소스는 이미 포함되어 있습니다.
리소스 생성 스크립트와 GLSL 검사 스크립트는 `tools/`에 있습니다.

- 실제 Minecraft/Fabric API 대상으로 Java 컴파일·remap 성공.
- 자동 테스트 50개 통과: 설정 이전, 지형 변경 API 참조 제거, 카메라 경로·회전 일치, 접촉 정지, 세 충격파와 종료 시점, 아토믹 37초 순서·피해 경계·매초 판정, 천문검 12.2초 순서·검 낙하/연속 속도·고정 접촉점 관입·두 손가락 자세와 실제 관절 모델 베이크.
- UUID별 상시 쿨타임 설정의 NBT 저장/복원·끄기·잘못된 항목 처리, 세 매니저의 설정 연동과 기존 기술 유지도 검사했습니다.
- 장검의 직선 검신·가드·손잡이·920블록 전체 크기, 구름의 깊이·빈 중앙·제한된 메시 수, 12–128블록 시전 거리에서 카메라 좌표를 검사했습니다.
- 실제 Java 렌더 메시와 카메라를 내보내 EGL/Mesa에서 합성 장면으로 확인했습니다. Minecraft 게임 화면은 아닙니다.
- 배포 JAR에 GIF 프레임과 재생 클래스가 없는지 확인합니다. 쿨타임 초기화의 진행 중 기술 보존과 GUI 렌더 순서도 검사합니다.
- 실제 GLSL을 headless OpenGL에서 컴파일·링크하고 3단계 후처리 실행 성공. 합성 이미지에서 빛 번짐·흑백·왜곡·속도선·효과 끄기와 아토믹 파편 셰이더의 움직임·흰 화면 없음(HUD의 2.3.2 효과와 별개)·천문검 금빛 색조와 주문 전환 때 후처리 초기화를 확인했습니다.
- 제공된 영상과 변환 오디오의 길이 및 파형 상관을 확인했습니다. 천문검 준비음 4.95초·충돌/관입음 7.2초의 길이, 구간별 편집 시각, 편집 PCM 대비 OGG 파형 상관도 확인했습니다. 실제 게임 청취 테스트는 아닙니다.
- JAR, 리소스, Mixin 매핑과 배포 묶음 무결성 검사.

**게임 내 플레이 검증은 아직 하지 못했습니다.** 합성 이미지 셰이더 검사는 실제 마인크래프트 화면 검증이 아닙니다.
게임 화면·효과음 청취·FPS·카메라 충돌·멀티플레이·다른 모드 호환은 실제 게임에서 확인해야 합니다.
문제가 있으면 `logs/latest.log` 또는 `crash-reports`와 재현 상황을 함께 확인할 수 있습니다.

독립 제작 코드·에셋은 MIT 라이선스입니다. 제공받은 영상의 오디오 `atomic_clip.ogg`, `atomic_charge.ogg`, `atomic_impact.ogg`, `heaven_charge.ogg`, `heaven_impact.ogg`, `heaven_release.ogg`는 MIT 라이선스 대상이 아닙니다. 원작 오디오·Minecraft·Fabric의 권리는 각 소유자에게 있습니다.
